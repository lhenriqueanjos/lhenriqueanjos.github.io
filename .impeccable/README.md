# Impeccable Configuration

Este diretório armazena configurações locais de workflow de design do sistema Impeccable para o site profissional.

## Índice

- README.md: documentação do diretório e índice de arquivos e subdiretórios.
- config.json: arquivo de configuração contendo definições de pipeline de build e workflow de design.
- design.json: sidecar estendido contendo ramps tonais, metadados de tipografia, sombras e tokens de componentes.
- live/: subdiretório de estado volátil de sessões em tempo real do live server.
- mocks/: subdiretório contendo dados e mocks de apoio a prototipação.
- questions/: subdiretório de sessões de perguntas interativas do workflow de design.
- surfaces/: subdiretório de contratos e surface briefs das interfaces.
