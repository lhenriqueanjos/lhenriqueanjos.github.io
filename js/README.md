# Scripts JavaScript

Este diretório contém os scripts de interatividade e animação para o site profissional estático.

## Índice

- README.md: documentação do diretório e índice de arquivos.
- main.js: script de controle de navegação acessível, rolagem suave e interações de interface.
- particles.js: simulação em HTML5 Canvas de partículas geométricas interativas com reação suave à rolagem da página e ao cursor.
